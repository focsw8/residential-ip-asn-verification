## 纯净住宅IP 和机房 IP、共享机场 IP 差在哪

差别落在 ASN 上。ASN 是自治系统号，一个号对应一段网络的归属，平台风控查的就是这个字段。市面上卖的所谓住宅 IP，按 ASN 大致分三档。

**第一档，真实住宅号段。** AS701 属于 Verizon，主要是 Fios 光纤家庭宽带；AS7018 是 AT&T，涵盖 DSL、光纤和无线；AS6079 是 RCN，区域性光纤运营商，号段集中。这三个的共同点是 ISP 类型显示为 Cable、DSL 或 Fiber，IP 行为接近普通用户，刷视频、逛社交、偶尔下载，很少被标记成代理。

**第二档，伪住宅。** 本质是机房或骨干网，被代理商包装成住宅卖。AS2914 是 NTT Communications，AS3257 是 GTT Communications，AS3356 是 Lumen（原 Level 3）。这三家的 WHOIS 记录写的是 backbone 或 transit，IP 行为更像服务器：高并发、长连接、稳定不断线。部分平台会直接判成 proxy 或 hosting。

**第三档，共享机场 IP。** AS16276 是 OVH，AS9009 是 M247，AS24940 是 Hetzner。同一个 IP 上挂着成百上千个用户，支付和社媒平台早就把这几段列入重点风控，验证码和封号大多从这儿来。

有意思的是，同一个 ASN 在不同商家嘴里能说出完全相反的结论。GetIPProxy 的纯净住宅列表里，加州一批 IP 标着“极净 IP 风控值 1”，ASN 写的是 NTT America, Inc. AS2914，单个 IP 30 天 $4.73。RESIP 官网的质量分级指南里，AS2914 被直接归进“伪住宅 IP”，理由是 WHOIS 显示骨干网、常被小代理商当住宅卖。两家都是公开页面，口径正面对立。

这说明“纯净度”这个评级是各家自说自话。GetIPProxy 的“风控值 1”是它自己观察到的历史信号，RESIP 的“伪住宅”也是它自己的分类标准。商品页上那几个字不能当证据，拿到 IP 之后查一下它归谁，比看标签靠谱。

## 怎么判断一个纯净住宅IP 是不是真的纯净

先看四条，再跑三步验证。

四条判断维度：IP 来源必须是真实住宅网络（Residential ISP），可以向服务商要一段 IP 样例，用 ipinfo.io 查 ASN 和 ISP 名称；匿名性和独享性，长期登录的账号要选独享静态，别用池内轮换的；定位精度，能不能精确到城市甚至邮编，能不能按州、按城市筛选；协议支持，至少要有 HTTP(S) 和 SOCKS5，方便塞进浏览器、脚本和指纹浏览器。

三步验证照着做：

**第一步，查 ASN 和类型。** 把 IP 丢进 ipinfo.io，看 org 字段里的 AS 号是不是前面第一档那几个，再看 type 是不是 `isp`。显示 `datacenter` 或 `hosting` 的，不管商品页怎么写，一律按机房 IP 处理。

**第二步，查风险分。** Scamalytics 给 0 到 100 的欺诈评分，0 分最好，超过 25 要留心。IPQualityScore 一起看，AbuseIPDB 看的是这个 IP 历史上有没有被举报滥用。三个库交叉，比单一来源可靠。

**第三步，验证出口位置。** 切到代理，访问 whatismyipaddress.com，看两件事：城市对不对得上你买的地区，ISP 是不是当地的家庭宽带运营商（比如 Spectrum、Comcast）。城市飘了，或者 ISP 显示成某某云、某某数据，这个 IP 就不该按住宅价卖给你。

有人会说自己买的是“双 ISP”。这个词指的是 IP 在两家 ISP 的数据库里同时注册，被 ipinfo 识别成 `isp` 而不是 `hosting`，不是营销话术，但也不能替代上面三步。验证方式一样：查 type、查风险分、查出口。

## 常见问题

### 动态住宅和静态住宅，我该选哪个

看你的业务是游击还是阵地。需要大量不同身份去访问，比如抓公开数据、做广告验证、批量测试，选动态住宅，按流量计费，成本低。需要几个固定可靠的身份长期驻扎，比如运营核心社媒账号、维护店铺登录环境，选静态住宅，独享、不轮换，按 IP 数量和时长计费。

### 原生住宅和广播住宅有什么区别

原生住宅的 IP 注册地和实际定位地一致，平台查注册信息时看到的是同一个地方。广播住宅是把别处的 IP 段广播到目标地区，成本低、可选地区多，但注册信号对不上。业务要求两者一致就选原生，只关心地区覆盖和预算就选广播。

### 用了纯净住宅IP，账号还会被亚马逊、谷歌封吗

会。没有任何服务商能保证 100% 不被封，平台风控是动态的，今天的干净 IP 明天可能就进库。住宅 IP 能把“IP 被识别为可疑来源”这一项风险压到很低，但账号行为、支付信息、浏览器指纹任何一环出问题，照样触发审核。控制访问频率、遵守 robots.txt，是长期使用的前提。

### 除了 IP，还要注意什么

浏览器指纹。Canvas、WebGL、字体列表、Cookie、时区和语言，平台会一起比对。只换 IP 不换指纹，多个账号还是会被关联到一起。做法是每个账号配一套独立的浏览器环境，IP、指纹、Cookie 全部对齐同一个地区。

### 到期忘了续费，还能拿回原来的 IP 吗

大概率不能。GetIPProxy 明确写了，必须在订单到期前续费才能继续使用同一个 IP，订单一到期原 IP 不再保留，之后重新购买可能分到新地址。养号的人把续费日记进日历，比什么补救都强。
